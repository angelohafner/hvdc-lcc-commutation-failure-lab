# Project instructions

- Keep code, documentation, interfaces and figures entirely in English.
- Only native PSCAD/EMTDC execution may produce engineering transient results.
- Keep original source files, execution receipts and hashes traceable. Never overwrite accepted raw evidence.
- Synthetic signals belong only in explicitly identified tests, never student datasets.
- Classify failures from valve current, gate and voltage evidence. Low gamma alone is insufficient.
- Keep ambiguous events inconclusive. Do not equate fault clearing with recovery, or persistent conduction with converter blocking.
- Browser controls select recorded cases. Declare any analytical approximation separately.
- Preserve all native samples in event views, SI units in processing, local dependencies and relative website paths.
- Run relevant Python and browser checks before a release. Do not claim hardware validation or complete numerical convergence.
- The owner resumed public GitHub and Pages publication on 16 November 2026. Publish only audited release files; preserve native raw evidence and local development history.
- Do not distribute PSCAD installations, master libraries, compiled executables, licensed examples, credentials or unrelated local files.
