# HVDC LCC Laboratory Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Build, validate, and publish a standalone PSCAD inverter study and eight English interactive learning pages.

**Architecture:** An original PSCAD six-valve model produces traceable time series. Python validates and classifies valve-level commutations, then exports static datasets and figures. A buildless HTML/SVG/JavaScript site presents measured results with synchronized cursors and explicit provenance.

**Tech Stack:** PSCAD 5.1.0, installed mhi.pscad, Python 3.11, NumPy, Matplotlib, Schemdraw, bundled mathematical rendering, static GitHub Pages.

**Spec:** The user's complete project specification, supplied in this chat as Pasted text.txt. Its requirements govern this plan.

## Global constraints

- All artifacts and final summaries are English.
- Inverter only; equivalent DC source, no full HVDC link.
- Never synthesize curves and call them PSCAD results.
- Low gamma alone does not prove failure; require valve current, firing, and voltage evidence.
- Preserve licensed installation content locally. Publish only original model references, scripts, permitted dependencies, and selected results.
- Use the requested public repository and main:/docs GitHub Pages.
- Establish baseline and first verified failure before the full campaign.

## Review focus

- Truncated or nonuniform output must fail data ingestion.
- Ideal thyristor recovery assumptions must remain visible.
- Event counting must not count two signals from one failed transfer as two events.
- Browser parameters must select measured cases or disclose analytical calculations.
- Offline paths and repository-subdirectory paths must both work.
